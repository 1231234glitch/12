# Project HINA — Unity

블루아카이브의 실제 공개 일러스트를 참고한 히나 중심 횡스크롤 액션 프로젝트입니다. 원본의 의상, 헤일로, 무기, 적과 보스의 형태·색상을 우선하여 새 포즈와 게임용 이미지를 제작했습니다. 공식 배포 게임이나 공식 추출 에셋이 아닙니다. 참고 주소와 제작 이미지 해시는 DESIGN_SOURCES.json에 기록했습니다.

## 열기와 조작

Unity Hub에서 `ProjectHINA` 폴더를 Unity **2022.3.62f1**로 엽니다. 최초 임포트 후 `Assets/Hina/Scenes/Bootstrap.unity`를 열고 Play를 누릅니다. 메뉴 `HINA`에서도 씬 열기와 빌드를 실행할 수 있습니다.

- 이동: A/D 또는 방향키, 사격: J, 점프: K, 특수기: L
- 조준: 위/아래 방향키, 일시정지: Esc
- 타이틀에서 시작·스테이지 선택·설정을 이용합니다.

5개 스테이지와 비나, 페로로지라, 호드, 고즈, 헤세드를 연결했습니다. 보스별 경고·공격·기믹, 소환체, 엄폐물 파괴, 점수·아이템·컨티뉴, 잠금 해제 저장과 음량 설정을 구현했습니다. 점프 입력 보정, 발판 충돌, 근접 공격과 특수기의 소환체 판정도 포함합니다.

## 이미지

히나, 헬멧단, 스케반, 카이저 병사·드로이드·전차, 보스 5종, 소환체, 소품과 배경을 포함한 8개 시트를 사용합니다. 144개 프레임, 150개 애니메이션 매핑, 43개 디자인 그룹입니다. 픽셀 아트가 아닌 부드러운 일러스트로 임포트하며, 시트별 실제 프레임 위치와 피벗을 적용합니다.

## 검증 상태

`VALIDATION.json`에 결과가 있습니다. 순수 C# 게임 로직 72개 검사와 C# 9 문법 검사, 이미지 해시·슬라이스·매핑 검사, 브라우저 아트 뷰어의 5개 스테이지 확인이 통과했습니다. `ArtReview`의 화면은 아트 배치 확인용이며 Unity 실행 화면이 아닙니다.

이 제작 환경에는 Unity 에디터와 활성화된 라이선스가 없어 **Unity API 컴파일, Unity Test Runner, 실제 플레이와 Windows/WebGL 실행파일 빌드는 미검증**입니다. 프로젝트를 완성된 실행파일로 간주하지 마세요. Editor/PlayMode 검사 9개를 포함했으며 Unity에서 실행해야 합니다.

## 빌드

활성화된 Unity와 대상 플랫폼 모듈을 준비한 뒤 `HINA` 메뉴의 Windows x64 또는 WebGL 빌드를 사용합니다. CI 템플릿과 안내는 `CI` 폴더에 있습니다. GitHub 워크플로가 설치된 경우 Actions에서 수동 실행할 수 있습니다. 라이선스 등 비밀 값은 채팅이나 저장소 파일에 넣지 않고 빌드 서비스의 보안 설정을 사용합니다.

## 독립 검사

Python 3/Pillow, .NET SDK 8이 설치된 환경에서 다음 명령을 실행합니다. `Tools/run_core_tests.py`는 SDK의 실제 Roslyn으로 코어 코드를 컴파일하며 Unity 대체 API를 사용하지 않습니다.

```sh
python3 Tools/run_core_tests.py
python3 Tools/check_unity_syntax.py
python3 Tools/validate_art.py
```

브라우저 검사 결과는 별도 아트 뷰어 실행 결과를 포함합니다. 실행하지 않은 Unity 검증을 대신하지 않습니다.
